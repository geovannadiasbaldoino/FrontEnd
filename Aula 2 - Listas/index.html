Criar listas em HTML

Listas são usadas para agrupar informações. Do ponto de vista estrutural,
as listas auxiliam a criar documentos organizados. Mas é importante você
ter atenção ao criar as listas, deve sempre abrir as marcações e não esquecer
de fechá-las corretamente!

No HTML, existem três tipos de listas:
ordered list (listas ordenadas);
unordered list (lista não ordenada);
description list (linhas de descrição).

Lista ordenada

As listas ordenadas são usadas para exibir itens em uma ordem definida,
por exemplo, ordem alfabética ou numérica.

Exemplo

  1. Item 1
  2. Item 2
  3. Item 3

Listas de Cidades

  1. São Paulo
  2. Minas Gerais
  3. Rio de Janeiro

E se quisermos começar do 50

Por padrão, uma lista ordenada começa do 1. E se quisermos começar do 50?
Podemos usar um atributo chamado start.

  1. Brasil
  2. China
  3. Estados Unidos
  4. Rússia
  5. Venezuela
  6. México

Lista Alfabética maiúscula:

  1. Morango
  2. Uva
  3. Banana

Listas não Ordenadas

A lista não ordenada não precisa ser apresentada em uma ordem sequencial.

Exemplo:

  • Cadeira Flexora
  • Stiff
  • Elevação Pélvica
  • Coice Polia
  • Cadeira Abdutora

Alterar o tipo de lista para quadrado:

  • Casa Térrea
  • Sobrado
  • Apartamento
  • Kitnet
  • Cobertura

Alterar o tipo de lista para discos (círculos vazios):

  • Batom
  • Base
  • Corretivo
  • Rímel

Listas Aninhadas em HTML

O HMTL permite criar listas dentro de listas.

Exemplo:

  • Item 1
  • Item 2
    1. Sub Item 1
    2. Sub Item 2
  • Item 3
